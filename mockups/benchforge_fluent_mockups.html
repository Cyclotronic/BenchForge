Interface direction · shipped

BenchForge Studio, dressed as bench software

Professional chrome, soft geometry. The menu bar, grouped toolbar, banded grids and multi-pane status bar make it read as an engineering tool; the rounded panels, roomy rows and lit status indicator keep it from feeling austere. This is what ships.

The decisions behind it

Six choices define the register — three structural, three about restraint.

Menu bar added
File · Edit · View · Emulator · Tools · Help

The single strongest signal that something is an application and not a utility script. Also gives keyboard-driven engineers the access keys they expect.

Corner radius
8px panels · 5px controls

Rounded enough to feel current, restrained enough to stay serious. Squaring these off tipped the whole thing austere, so they stayed soft.

Density
rows 28px · chrome 13px

Comfortable over a long session. Tightening to 22px fit a third more rows but made the app tiring to read all day.

Toolbar, not floating buttons
grouped · vertical separators

Commands cluster by function with rules between groups, the way Office and VS have done it for twenty years.

Colour, spent in one place
status glow 9px bloom

Tiles lost their tinted fills and sit on hairline dividers, so the only real glow in the app is the thing you check from across the desk.

Real data grids
banded rows · sort carets · header rules

Zebra striping and a sort indicator make a table look operable rather than printed.

Palette

Unchanged from rev 1 — it was doing its job. Semantic colours stay separate from the accent so a pass state never reads as a selection.

Building it in Qt

The current core/gui_qt.py calls setStyleSheet at roughly a dozen sites, which is why the look drifts between panels. One sheet at QApplication level fixes that.

Mockup elementQt widget & approach
Menu barQMainWindow.menuBar() — you get access keys and the native look for free. Wire Emulator → Start / Stop to the same QActions the toolbar uses.
Toolbar + separatorsQToolBar with addSeparator(); setToolButtonStyle(ToolButtonTextBesideIcon).
Navigation railQListWidget, frameless, setIconSize(20). Selection stripe is ::item:selected { border-left: 2px solid accent; }. Replaces QTabWidget.
Status bar panesstatusBar().addPermanentWidget() for the right-hand panes; separators come from styling QStatusBar::item.
Status LEDQLabel with the dot as rich text. At this glow level a border ring is enough — no QGraphicsDropShadowEffect needed any more.
PanelsQFrame with objectName("Panel"), styled once via QFrame#Panel. Never inline.
Banded data gridQTableWidget + setAlternatingRowColors(True), setShowGrid(False), verticalHeader().hide(), row height 22.
Sort caretssetSortingEnabled(True) — the header draws its own indicator; just colour it via QHeaderView::down-arrow.
SparklineQWidget subclass with a paintEvent: polyline plus filled polygon. About 30 lines.

Four things worth knowing

  • QSS has no box-shadow and no color-mix. Pre-compute tinted borders as literal hex in the dict. At rev 2's colour levels you no longer need shadows anywhere except flyouts.
  • Follow the OS theme. QApplication.styleHints().colorScheme() reports light or dark, and colorSchemeChanged fires when the user flips it — swap the dict, re-apply the sheet.
  • Cascadia Mono may be absent on older Windows 10. Check QFontDatabase.families() and fall back to Consolas, which is always present.
  • Enable high-DPI rounding before constructing QApplication, or 1 px hairlines render unevenly at 125% and 150% scaling — and this design leans on hairlines heavily.
